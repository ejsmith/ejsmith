# Eric J. Smith

Founder · Distinguished Engineer · Builder

I've been writing software since 1991 and I'm still a builder at heart. Along the way I bootstrapped two software companies, [CodeSmith Tools](https://www.codesmithtools.com) and [Exceptionless](https://exceptionless.com). Today I'm a Distinguished Engineer at [Concord Finance](https://concordfinance.com/technology/link), where I led the greenfield build of Concord Link, the loan servicing platform replacing a 40-year-old system.

I use AI agents to take on projects that once needed a whole team, inside complete loops where agents build, test, review and fix their own work so quality and consistency stay high. AI amplifies judgement, good or bad, so the part that hasn't changed is knowing what's worth building.

### Open source

- **[Exceptionless](https://github.com/exceptionless/Exceptionless)**: open-source error and event monitoring. 34M+ NuGet downloads, 3.5M+ Docker pulls and 3.5k stars across its projects.
- **[Foundatio](https://github.com/FoundatioFx/Foundatio)**: pluggable building blocks for distributed .NET apps (caching, queues, locks, messaging, file storage and jobs). 2.5k stars and 53M+ downloads.
- **[Foundatio.Mediator](https://github.com/FoundatioFx/Foundatio.Mediator)**: a convention-based mediator built on source generators, with near direct-call performance.
- **[Jint.Workflows](https://github.com/FoundatioFx/Jint.Workflows)**: durable JavaScript workflows for .NET. Powers the workflow engine in Concord Link.

Also contributed to OpenTelemetry .NET, Jint, ASP.NET Core and Svelte.
